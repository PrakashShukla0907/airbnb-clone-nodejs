# 🏠 Airbnb Clone - Full Stack Project

A responsive web application that mimics the core functionality of Airbnb.

## 🚀 Features
- **User Authentication:** Secure Signup/Login using `bcryptjs` for password hashing.
- **Session Management:** Persistent login sessions using `connect-mongo`.
- **Role-Based Access:** Separate dashboards for **Guests** (to book) and **Hosts** (to list properties).
- **Property Management:** Create, Read, Update, and Delete (CRUD) property listings.
- **Responsive UI:** Modern, clean interface built with **Tailwind CSS** and **EJS** templates.
- **Database:** MongoDB integration using **Mongoose** for structured data modeling.

## 🛠️ Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose)
- **Frontend:** EJS, Tailwind CSS
- **Auth:** Express-Session, BcryptJS
